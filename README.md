# BinaryTasks

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

[🌍 Ver en español](#espanol)
[🌍 View in english](#english)

BinaryTasks is a set of tools designed to automate and manage development tasks in today's work environments. With the aim of simplifying the creation of projects, the configuration of repositories and other tasks involved in achieving a software project, scripts, configurations and templates are included that allow software developers and architects to accelerate their workflow.

---

## 🚀 Features

- Automatically create a project folder locally.
- Initialize the project repository remotely on GitHub.
- Pre-configured license file (MIT, Apache, GPL-3.0, etc.).
- Automatically generated README.md file with a generic project description.
- GitHub repository visibility settings (Public/Private).
- Fully customizable project setup for different environments and use cases.

---

## 📦 Installation

### Prerequisites

Before using `binaryTasks`, you need to have the following tools installed:

- **GitHub Personal Access Token (PAT)**: [Generate a GitHub Token](https://github.com/settings/tokens)
  
### Setup

1. Clone the repository:

    ```bash
    git clone https://github.com/yourusername/binaryTasks.git
    ```

2. Navigate to the project folder:

    ```bash
    cd binaryTasks
    ```

3. Set your GitHub token as a system environment variable GITHUB_TOKEN, or add it to your `.env` file.

4. Set up your environment by creating a `.env` file using the .`.env.example` file provided. Update your GitHub token and other environment variables.

---

## 🔧 Usage

So far this tool will guide you through the process of setting up a new project with the following steps:

1. Choose the project name format (e.g., camelCase, snake_case).
2. Specify your GitHub repository visibility (Public or Private).
3. Select the desired license for the project.
4. Automatically generate a README.md and LICENSE file.
5. Push the new repository to GitHub.

### ¿Qué es BinaryTasks?

BinaryTasks es un conjunto de herramientas diseñado para automatizar y gestionar tareas de desarrollo en entornos de trabajo actuales. Con el objetivo de simplificar la creación de proyectos, la configuración de repositorios y demas tareas que implique la consecucion de un proyecto de software, se incluye scripts, configuraciones y plantillas que permiten a los desarrolladores y arquitectos de software acelerar su flujo de trabajo.

---

## 🚀 Características

- Crea automáticamente la carpeta del proyecto de manera local.
- Inicializa el repositorio del proyecto de manera remota en GitHub.
- Archivo de licencia preconfigurado (MIT, Apache, GPL-3.0, etc.).
- Archivo README.md generado automáticamente con una descripción genérica del proyecto.
- Configuración de visibilidad del repositorio en GitHub (Público/Privado).
- Configuración totalmente personalizable para diferentes entornos y casos de uso.

## 📦 Instalación

### Requisitos previos

Antes de usar `binaryTasks`, necesitas tener instaladas las siguientes herramientas:

- **Token de acceso personal de GitHub (PAT)**: [Generar un token en GitHub](https://github.com/settings/tokens)

### Configuración

1. Clona el repositorio:

    ```bash
    git clone https://github.com/yourusername/binaryTasks.git
    ```

2. Navega a la carpeta del proyecto:

    ```bash
    cd binaryTasks
    ```

3. Configura tu token de GitHub como variable de entorno GITHUB_TOKEN en tu sistema o agrégalo a tu archivo `.env`.

4. Configura tu entorno creando el archivo `.env` utilizando el archivo `.env.example` proporcionado. Actualiza tu token de GitHub y otras variables de entorno.
